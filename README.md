# telegram-sap-sales-order-automation
Practice project demonstrating Telegram-based SAP sales order automation using SAP SD process concepts and API integration.

## Repository Contents

- `README.md` - Project overview and setup information.
- `telegram_sap_odata_bot_v5.py` - Main Telegram and SAP automation script.
- `run_telegram_sap_bot.bat` - Local execution helper.
- `credentials.env.example` - Safe configuration template containing placeholders only.
- `sales_orders_sample.xlsx` - Fictional sample sales-order data for demonstration.
- `telegram_sap_odata_bot_sample.log` - Non-sensitive sample execution log.
- `.gitignore` - Prevents accidental upload of local credentials and temporary files.

## Sample Data and Security

The configuration template contains placeholders only. The spreadsheet contains fictional test data, and the log file does not contain credentials or private system information.

Never replace the placeholders with real credentials in a public repository. Use a local environment file and keep it excluded through `.gitignore`.
